# IT4023E - Data Visualization Capstone Project

## Introduction

This is a Capstone Project for the subject IT4023E - Data Visualization. The project explores a dataset of layoffs and presents an interactive dashboard alongside supporting report materials.

## Project Structure

```text
IT4023E_DataVisualization/
├── assets/
│   └── LayoffDV.pdf
├── dashboard/
│   └── LayoffDV.pbix
├── data/  
│   └── layoffs.csv
└── report/
    ├── dashboard_report.pdf
    ├── dashboard_slides.pdf
    └── book_presentation/  # book presentation slides
        └── chapter16_slides.pdf
```

- `assets/LayoffDV.pdf`: Dashboard PDF file that contains the visualization output.
- `dashboard/LayoffDV.pbix`: Power BI dashboard source file used to build and interact with the visualization.
- `data/layoffs.csv`: Dataset used in the dashboard and analysis.
- `report/dashboard_report.pdf`: Final written report for the capstone.
- `report/dashboard_slides.pdf`: Presentation slides for the capstone.
- `report/book_presentation/chapter16_slides.pdf`: Book presentation slides.

## Notes

- This repository is organized to separate data, visualization code, assets, and report deliverables.
